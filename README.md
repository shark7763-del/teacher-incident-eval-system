# 學校教師事件紀錄與教評輔助系統

> Faculty Incident Record & Evaluation Support System

以「客觀事實」為核心，協助學校行政人員紀錄教師疑似違規 / 教學不力 / 輔導管教不當 / 行政違失等事件，並依不適任教師相關程序做案件分流、輔導改善追蹤、程序檢核與教評會資料彙整。

本系統定位為 **「事件紀錄、輔導改善、程序檢核、教評資料彙整」** 的行政輔助工具，**非單向蒐集教師把柄**；案件分流僅提供「行政建議」，不直接判定教師是否適任，正式處理仍須依教師法及相關法令之法定程序辦理。

## 功能

- 首頁儀表板（本月新增 / 待處理 / 輔導追蹤 / 即將到期 / 高風險 / 事件類型統計）
- 教師基本資料管理（CRUD、查詢）
- 事件紀錄管理（自動編號、多條件篩選、時間軸、佐證附件）
- 案件分流建議（依事件類型 × 嚴重程度）
- 行政晤談與輔導改善紀錄（到期提醒、輔導報告）
- 教評會資料彙整（可列印資料包）
- 程序檢核表（11 項）
- **學生事務（獨立模組）**：學生基本資料管理（CRUD）＋學生事件紀錄（自動編號、四類型「輔導個案／出缺勤生活常規／偏差行為獎懲／學習成績關注」、關注程度、處理老師、可連結教師事件、追蹤提醒、佐證附件、機密標籤、統計卡）
- 6 種角色權限控管（校長 / 人事 / 教務學務 / 導師行政 / 教評委員 / 系統管理員）
- 個資保密設計（機密標籤、去識別化匯出、操作稽核軌跡）
- 匯出 CSV / JSON、可列印 HTML 報告

## 技術

- 純前端單一檔案 `index.html`（HTML + CSS + JavaScript），免安裝、雙擊即用
- 資料預設存於瀏覽器 `localStorage`
- **佐證附件（照片 / 影片 / 檔案）**：
  - 預設存本機（縮圖與檔名存 localStorage，檔案本體存 IndexedDB）
  - 選用雲端模式：透過 `Code.gs`（Google Apps Script）將檔案存進 Google Drive、清單寫入 Google 試算表，可跨裝置調閱

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 系統本體，單檔即可執行 |
| `Code.gs` | （選用）Google Drive 雲端附件後端，部署方式見檔案開頭註解 |

## 使用方式

1. 直接用瀏覽器開啟 `index.html`
2. 模擬登入選擇身分即可操作（首次開啟會載入少量示範資料）
3. 如需雲端附件，依 `Code.gs` 開頭說明部署後，於「系統設定」貼上 GAS 網址啟用

## 隱私與保密

本系統處理教師個資與含學生影像之敏感案件。請務必：

- 限定存取人員、落實權限控管
- 雲端附件務必妥善保管網址、限定資料夾權限
- 正式上線建議使用學校 Google Workspace 帳號，而非個人 Gmail
- 不得將資料外流，並遵守程序正義與個資保護相關規範
